控制台一个记忆点。

六个方向都以“小尺寸先行”为原则：不依赖文字，在 16px 的浏览器标签上仍能辨认。点击任一方案，可在底部查看它放进真实浏览器标签和桌面图标后的感觉。

主色
最小尺寸16 × 16 px
应用场景Web / PWA

汇流方格

A / CONFLUENCE

四个任务块向中心汇聚，负形里藏着一个 C；最像“多平台聚合”的产品本质。

课程画布

B / CANVAS

把课表、任务、提醒放进同一块四分画布；信息密度高，仪表盘属性最强。

截止轨迹

C / DEADLINE

时钟缺口转化为完成勾，强调“看见截止时间，然后完成它”的核心动作。

任务折页

D / PAGE

一张带折角的课程任务单，最直白、亲和，适合以“作业管理”为第一认知。

聚合路径

E / ROUTE

多个来源沿路径收束为一个下一步；比方格更动态，也呼应项目里的 Next Action。

CD 字标

F / MONOGRAM

C 与 D 共用轮廓，品牌指向最直接；形式稳重，适合未来扩展到桌面端。
