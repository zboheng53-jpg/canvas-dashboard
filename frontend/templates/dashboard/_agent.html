安全授权
第一步 · 凭据

专属 Agent API Token

Token 具有与你账户相同的操作权限（查询课表、读写待办），请妥善保管。重新生成或撤销会立即使旧 Token 失效。

生成 Token 后，即可下载配置包或在 Agent 中连接。
