现状痛点剖析（为什么会觉得特别丑陋）

• 灰色实心大面板：展开子任务后插入一块大面积灰色底色卡片，界面产生明显“补丁感”，割裂了待办列表的清爽流线。

• 原生 DatePicker 霸占面积：每一行都横亘一个 140px 宽的笨拙原生日期输入框，反客为主，完全盖过了任务文本本身。

• 裸露刺眼的红色“x”：删除按钮无图标包裹、无悬停渐变，像未完成的粗糙毛坯页面。

• 缺乏层级引导：子任务与父任务缺乏柔和的缩进指引线或视觉呼应。

弹窗保存密码 Bug 深度排查与修复说明

• 为什么会跳“保存密码 cann”？ 浏览器密码管理器会对页面所有未被 `<form>` 包裹的孤立控件统一识别为同一个隐式表单。设置页中的“退出其他设备密码框”之前未包裹在表单内，且被 Edge 自动填充了记住的用户名（cann）。

• 触发机制：在子任务中按回车提交时，未被表单保护的子任务输入框触发了 PUT 请求，Edge 误认为整个孤立表单（含密码框）被提交，因此疯狂弹出密码保存提示！

• 彻底优化：已将设置页密码框封装进独立 `<form>`，并将子任务输入行包裹为带 `autocomplete="off"` 的独立微表单，彻底阻断误判！
